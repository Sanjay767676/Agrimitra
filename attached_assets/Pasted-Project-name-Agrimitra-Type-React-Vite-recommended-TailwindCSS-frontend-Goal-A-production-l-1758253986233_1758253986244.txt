======== Chatbot (KRISHI SAKHI) workflow ========
- System prompt (in code comments) to send to AI:
  "You are KRISHI SAKHI, a friendly farming companion. Use the farmer's profile and recent weather to give short, actionable advice. Use emojis and a conversational, non-technical tone. If recommending irrigation, reference temperature and rain forecast. Keep answers concise and helpful."
- handleSendMessage(messageText) flow:
  1. Determine ChatbotLanguage from profile (default Malayalam)
  2. If message language ≠ English:
     - translateText(messageText, source=ChatbotLanguage, target='en')
     - (For demo: browser-based translation stub or call Translate API using TRANSLATE_API_KEY)
  3. fetchWeather(profile.location || geolocation) -> temp, humidity, forecast
  4. Build AI prompt including:
     - Farmer profile summary (name, crop, soil, irrigation, land size)
     - Weather snapshot (temp, humidity, condition, rain probability)
     - Recent conversation context (last 3 messages)
     - Clear instructions for actionable advice (include rules: if temp >35°C recommend irrigation; if raining advise against irrigation; if humidity high + crop=paddy say favorable)
     - Friendly tone + emojis + short steps
  5. callAI(prompt) -> get englishResponse
     - callAI should be a wrapper for OpenAI/Gemini (server-side proxy recommended). For prototype a client call with REACT_APP_OPENAI_KEY is acceptable but add security note in README.
  6. If ChatbotLanguage ≠ English:
     - translateText(englishResponse, source='en', target=ChatbotLanguage)
  7. Append translated response to chat and persist
  8. If TTS enabled -> ttsSpeak(responseText, lang=ChatbotLanguage)

======== STT (Mic) & TTS (Speaker) details ========
- Provide two operating modes for both STT and TTS:
  - `browser` mode (demo): uses Web Speech API
    - STT: window.SpeechRecognition (or webkitSpeechRecognition) for live speech-to-text
      - Implement UI: mic button toggles recording; show live transcription; on finish call handleSendMessage(transcript)

    - TTS: window.speechSynthesis for playing KRISHI SAKHI responses
      - ttsSpeak(text, langCode) chooses matching voice if available; includes fallback to English
  - `google` (cloud) mode (production placeholder):
    - STT: Google Cloud Speech-to-Text (send recorded audio to backend endpoint)
    - TTS: Google Cloud Text-to-Speech (get audio bytes from backend, play via Audio element)
    - Provide clear placeholders and comments where a server-side proxy endpoint must be implemented for security and audio streaming

- In README and code comments: explain browser demo is adequate for hackathon; for production recommend using server-side credentials and not embedding keys in frontend

======== Weather & Alerts implementation ========
- fetchWeather(location):
  - Call OpenWeather Current Weather + OneCall/Forecast for 3-day outlook using REACT_APP_OPENWEATHER_KEY
  - Return object {tempC, humidity, condition, rainProb24h, forecastArray}
- generateAlerts(weather, profile):
  - If rainProb24h > 0.6 -> Rain alert "Rain expected — delay spraying/irrigation"
  - If tempC > 35 -> Heat alert "High temp — consider irrigating"
  - If humidity > 85 && profile.crop includes 'paddy' -> "High humidity — good for paddy growth"
  - Add alerts with uid, severity, createdAt; store to local state/Firebase
  - On new alert: create a short KRISHI SAKHI message via callAI or via a template translated into ChatbotLanguage and append to chat
